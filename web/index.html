1 Your game

Drop your game folder or a .zip here

It's the folder with OMORI.exe and www in it. On Steam, right-click the game, go to Manage and pick Browse local files.

Now drop Steam's appinfo.vdf here

The game's files are encrypted, and Steam keeps the key in this file instead of the game folder. Only OMORI's key is read from it. It's in the appcache folder of wherever Steam is installed:

  • Windows: C:\Program Files (x86)\Steam\appcache
  • Mac: ~/Library/Application Support/Steam/appcache (press Cmd+Shift+G in the file picker to type it)
  • Linux: ~/.local/share/Steam/appcache, or ~/.var/app/com.valvesoftware.Steam/.local/share/Steam/appcache for the Flatpak (press Ctrl+L in the file picker to type it)

It's saved in this browser, so next time you won't have to pick it again.
